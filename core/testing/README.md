# Test infrastructure (`:core:testing`, `:core:ui-testing`)

Shared helpers for every Taqvim test suite (docs/PLAN.md T-005, §8). `:core:testing` is pure JVM and is added
to every module's `testImplementation` by the convention plugins; `:core:ui-testing` is the Android/Compose
counterpart used by `:core:ui`, `:feature:*` and `:app`.

## Golden fixtures (externally published reference data)

Golden fixtures live under `src/test/resources/golden/<area>/` of the module that uses them. Every file starts
with a provenance header of `#`-prefixed `key: value` lines, followed by the data:

```text
# source: University of Tehran, Institute of Geophysics — Official Calendar 1404
# url: https://example.org/calendar-1404.pdf
# retrieved: 2026-09-13
# page: 12
# reviewer: pending
# notes: optional free text
1404-01-01,2025-03-21
```

- Required keys: `source`, `url` (http/https), `retrieved` (ISO-8601 date), `reviewer`. Optional: `page`, `notes`.
- Load with `GoldenFile.load("golden/<area>/<file>")`; the body is available as `body` or non-blank `lines`.
- `FixtureProvenanceKonsistTest` fails the build when any golden fixture lacks a valid header (plan §8.2).
- Fixtures are immutable: changing one requires a PR with a justification and an updated citation.
- Record every dataset/fixture source in `docs/PROVENANCE.md`. Never copy fixtures from GPL/LGPL projects.

## Snapshots (output generated by Taqvim itself)

Self-generated expectations (for example the T-202 formatting matrix) live under `src/test/resources/snapshots/`
and start with `# generated-by: <test>`. Verify with `SnapshotVerifier().verify(file, actual, "<test>")`.
After reviewing an intended change, rewrite them with:

```shell
./gradlew :<module>:test -Ptaqvim.updateSnapshots=true
```

## Time

- `FakeClock` implements `kotlin.time.Clock`; it starts at Nowruz 1405 (Tehran) and moves only via
  `advanceBy`/`setTo`.
- `FakeTimeZone` simulates the device time zone; `TimeZones` lists the zones every date/time test should cover
  (Tehran, Kabul, Kathmandu, Berlin, Los Angeles, UTC).

## Screenshots (`:core:ui-testing`)

Every screen and widget is captured for light/dark/black × LTR/RTL × font scale 1.0/1.3/2.0 × phone
(412×915) / tablet (1280×800) / fold (673×841) — `ScreenshotMatrix.full()`, 54 environments.

```kotlin
@RunWith(ParameterizedRobolectricTestRunner::class)
@GraphicsMode(GraphicsMode.Mode.NATIVE)
class MonthScreenScreenshotTest(private val environment: ScreenshotEnvironment) {
    @get:Rule val composeRule = createComposeRule()

    @Test
    fun monthScreen() = composeRule.captureScreenshot("month_screen", environment) { MonthScreen(preview) }

    companion object {
        @JvmStatic
        @ParameterizedRobolectricTestRunner.Parameters(name = "{0}")
        fun environments() = ScreenshotMatrix.parameters()
    }
}
```

- Record references: `./gradlew :<module>:recordRoborazziDebug`; commit `src/test/screenshots/**`.
- Verify (CI): `./gradlew verifyRoborazziDebug`.
- `LocalScreenshotTheme` tells the app theme which variant (including AMOLED black) to render.
