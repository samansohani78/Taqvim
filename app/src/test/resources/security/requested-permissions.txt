# T-1804 (ADR-0017, ADR-0051, ADR-0054, ADR-0055): every permission the merged app manifest requests, and why. A permission
# that appears in the merged manifest and not here fails the build, and one listed here that no longer appears
# fails too, so a dependency cannot quietly add or drop one.
#
# Two checks read this file, because they see different manifests:
#   - ExportedComponentsTest reads the debug unit-test manifest;
#   - auditReleasePermissions reads the merged RELEASE manifest, which is what users install.
# Both must agree with this list. The release one is the proof that matters for a privacy claim: the debug
# manifest can differ, and a test-only dependency could mask a permission the shipped APK still requests.
#
# Calendar: READ_CALENDAR and WRITE_CALENDAR must NEVER appear here. Taqvim does not read the user's calendar
# (ADR-0051). Interoperability is file-based .ics import and export, through the Storage Access Framework, which
# needs no permission at all.
#
# Network: INTERNET and ACCESS_NETWORK_STATE must NEVER appear here either. Remote calendar subscriptions were the
# only feature that opened a socket and they were removed with the permission (ADR-0054), so Taqvim's own code
# cannot reach the network. A citation the user taps is handed to their browser, which is another app.
#
# Location: ACCESS_FINE_LOCATION and ACCESS_COARSE_LOCATION must NEVER appear here either (ADR-0055). Prayer times,
# Qibla and sky positions need coordinates, not a permission: they come from the bundled city catalog, a point on
# the map or coordinates the user types. Nothing in Taqvim asks the device where it is.
#
# permission | why
android.permission.RECEIVE_BOOT_COMPLETED | T-604 re-plans alarms after a restart, which Android otherwise drops
android.permission.SCHEDULE_EXACT_ALARM | T-1102 athan and T-1001 reminders have to sound at a time, not eventually
android.permission.FOREGROUND_SERVICE | T-1102 plays the athan while the screen is off
android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK | T-1102 the typed foreground service Android 14+ requires for it
android.permission.POST_NOTIFICATIONS | T-1001 reminders and the persistent date notification; the one dangerous permission left, requested at the switch that turns such a feature on and never at startup
android.permission.VIBRATE | T-1101 optional vibration with an athan
android.permission.WAKE_LOCK | T-604 finishes a scheduled alarm's work before the device sleeps again
android.permission.ACCESS_NOTIFICATION_POLICY | T-1101 lets the Fajr athan sound during Do Not Disturb, only if the user turns that on
