# Iranian primary sources (`docs/sources/iran/`)

Documents supplied by the repository owner (downloaded in a browser because calendar.ut.ac.ir blocks non-browser
clients); the Supplied column is the date each reached the repository. Publisher of the calendars, timetables, notices
and lists: Calendar Center, Institute of Geophysics, University of Tehran — https://calendar.ut.ac.ir/Fa/ (address
printed in the documents). Exact download URLs: to be added by the owner.

Canonical names are what the tools and fixtures cite; yearly calendars are renamed `Calendar-<year>.pdf`, and the
Original name column keeps the name the file was supplied under. Kinds: yearly-calendar, holiday-list, year-overview,
nowruz-instants, leap-year-table, prayer-timetable, notice, paper. Layout ids are defined in
`tools/sources/iran/official_calendar_sources.py`. Papers are references only: they are cited in `docs/PROVENANCE.md`,
nothing is copied from them, and the files are not archived in the repository (third-party copyright, as decided for
the van Gent pages on 2026-09-15; `.gitignore` here keeps the owner's copies out of Git). `tools/sources/iran/`
tests check every row's SHA-256 and size against the file.
